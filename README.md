# Wedha's Portfolio Website

Personal portfolio website showcasing my work as a Software Engineer and Engineering Manager with 9+ years of experience.

🌐 **Live Site**: [wedha.site](https://wedha.site)

## Overview

A modern, responsive portfolio featuring:

- **Hero Section** — Introduction with photo and availability status
- **What I Do** — Core competencies and services
- **Experience & Education** — Career timeline and skills
- **Featured Projects** — Public work and side projects (enterprise work is confidential)
- **Blog** — Latest articles from Medium
- **Contact** — Email, WhatsApp, and social links

## Tech Stack

- HTML5
- CSS3 (Vanilla CSS with custom properties)
- Vanilla JavaScript
- Google Fonts (Inter, JetBrains Mono)

## Structure

```
├── index.html      # Main HTML file
├── styles.css      # Stylesheet with design tokens
├── script.js       # JavaScript for interactions
└── assets/
    ├── favicon.png # Site favicon
    ├── photo.png   # Profile photo
    └── blog/       # Blog post images
```

## Features

- Responsive design (mobile-first)
- Smooth scroll navigation
- CSS scroll snap sliders for projects and blog
- Animated hero section
- Glassmorphism navigation bar
- Gradient accents and micro-animations

## Running Locally

Simply open `index.html` in your browser, or use a local server:

```bash
npx serve .
```
